---
title: "All projects"
description: "See the tasks of every project in one place."
---

Choose **All projects** in the sidebar to see every task in the workspace together. The view offers the same **Backlog**, **Tasks** (Board or List), **Calendar**, and **Gantt** views as a single project. Each task shows a tag with the name of its project.

Projects that share a status, such as **To Do** or **Done**, share a column. A status that exists in only one project gets its own column.

Click a task to open its details, where you can change its status, owner, or dates. Because each project has its own workflow, tasks cannot be dragged between columns or reordered in this view; do that from the project itself. When you create a task here, pick the project it belongs to.

Archived projects are not included.
